
# Marketplace AI — Анализ отзывов и семантический поиск контекста

**Marketplace AI** — Python-приложение для анализа отзывов покупателей маркетплейсов, классификации по тональности и тематике, а также формирования ответов с использованием правил и семантического поиска по локальной базе знаний.

Проект демонстрирует интеграцию текстовых embeddings в прикладной NLP-процесс: модель `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` кодирует тексты, а косинусная близость помогает выбрать релевантный контекст для ответа.

> **Границы реализации:** текущая версия не вызывает генеративную LLM и не выполняет fine-tuning. Ответы формируются по правилам и шаблонам, дополненным найденным контекстом. Это retrieval-augmented подход, а не полноценная генеративная RAG-система.

## Возможности

- Импорт отзывов из CSV в SQLite.
- Очистка текстов: приведение к нижнему регистру, удаление знаков пунктуации и лишних пробелов.
- Определение тональности по числовому рейтингу: 4–5 — положительная, 3 — нейтральная, 1–2 — отрицательная.
- Тематическая классификация по ключевым словам: доставка, проблема с товаром, качество товара, другое.
- Выделение нескольких аспектов и обработка смешанных отзывов с помощью эвристических правил.
- Формирование базового ответа на основе типа отзыва и обнаруженных аспектов.
- Семантический поиск фрагментов локальной базы знаний и добавление подходящего контекста к ответу.
- Просмотр данных, метрик, диаграмм и примеров ответов в Streamlit.

### Как работает семантический поиск

1. Локальная база знаний содержит заранее подготовленные фразы по четырём темам.
2. `SentenceTransformer("paraphrase-multilingual-MiniLM-L12-v2")` создаёт embeddings фраз базы знаний; вычисления кэшируются средствами Streamlit.
3. Для нового отзыва вычисляется embedding запроса.
4. `cosine_similarity` сравнивает запрос с фразами соответствующей темы.
5. Если максимальная близость не ниже `0.3`, выбранный контекст проходит дополнительную фильтрацию и при необходимости добавляется к шаблонному ответу.
6. Для положительных отзывов используется базовый ответ без добавления контекста.

**Важно:** в текущей версии нет FAISS, отдельной векторной БД или генерации текста LLM. Векторный поиск выполняется по embeddings в памяти приложения.

## Установка и запуск

Требуется Python и доступ к интернету при первой загрузке модели SentenceTransformer.

```bash
# Из корневого каталога проекта
python -m venv .venv
```

Активация окружения:

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

```bash
# Linux/macOS
source .venv/bin/activate
```

Установка зависимостей (в текущем архиве нет `requirements.txt`):

```bash
pip install pandas streamlit sentence-transformers scikit-learn sqlmodel
```

Создание базы данных и импорт примеров:

```bash
python -m init_db
python -m scripts.import_reviews
python -m scripts.check_reviews
```

Запуск интерфейса:

```bash
streamlit run dashboard/app.py
```

> Команды отражают структуру исходного кода; полный запуск в текущей среде не проверялся. Запускайте их из корня репозитория. Повторный импорт CSV добавит дублирующие записи, поскольку в скрипте нет проверки уникальности.

## Особенности и ограничения

- **Тональность** определяется рейтингом, а не обученным классификатором тональности.
- **Темы и аспекты** определяются по ключевым словам; это интерпретируемый, но ограниченный подход.
- **Смешанные отзывы** выявляются эвристически, поэтому возможны ложные срабатывания.
- **Ответы** собираются из заранее заданных формулировок; модель embeddings выбирает релевантный контекст, но не генерирует новые предложения.
- **База знаний** небольшая и хранится непосредственно в `dashboard/app.py`.
- В архиве отсутствуют автоматизированные тесты и файл фиксации зависимостей; количественные показатели качества модели не заявляются.
