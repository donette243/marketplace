
# Marketplace AI — Интеллектуальная система анализа отзывов

**Marketplace AI** — проект интеллектуальной системы для автоматизации обработки и анализа клиентских отзывов на маркетплейсах.

Система объединяет методы обработки естественного языка (NLP), машинного обучения (ML) и инструменты анализа данных для классификации отзывов, определения их тематики и автоматизации подготовки ответов клиентам.

## 1. Цель проекта

Разработка интеллектуального решения для автоматизации работы с пользовательскими отзывами на торговых площадках.

Основные задачи:

- Автоматизация анализа клиентских отзывов.
- Определение эмоциональной окраски текста.
- Классификация отзывов по тематическим категориям.
- Подготовка ответов с учётом содержания отзыва.
- Централизованное хранение и обработка данных.
- Повышение эффективности обработки обратной связи.

## 2. Основные функциональные возможности

### 2.1. Сбор и хранение данных

- Импорт пользовательских отзывов.
- Структурирование текстовых данных.
- Хранение информации в SQLite.
- Подготовка данных для последующего NLP-анализа.

### 2.2. Анализ тональности (Sentiment Analysis)

Автоматическое определение эмоциональной окраски отзывов.

Поддерживаемые категории:

- Positive — положительный отзыв.
- Negative — отрицательный отзыв.
- Neutral — нейтральный отзыв.

Анализ тональности позволяет выделять отзывы, требующие повышенного внимания.

### 2.3. Тематическая классификация

Автоматическое определение основной тематики пользовательского отзыва.

Категории:

- Доставка.
- Проблемы с товаром.
- Качество товара.
- Другое.

Классификация помогает структурировать обращения и выявлять распространённые проблемы.

### 2.4. Автоматизация ответов

Подготовка ответов на пользовательские отзывы с учётом:

- Содержания сообщения.
- Определённой тональности.
- Тематики обращения.
- Смешанных отзывов, содержащих положительные оценки и жалобы.

## 3. Архитектура системы

Общая схема обработки данных:

```text
           Отзывы пользователей
                    |
                    v
             Импорт данных
                    |
                    v
        Предобработка текста
                    |
                    v
             NLP-анализ
                    |
          +---------+---------+
          |                   |
          v                   v
   Анализ тональности   Классификация тем
          |                   |
          +---------+---------+
                    |
                    v
       Формирование результатов
                    |
                    v
        Подготовка ответов
                    |
                    v
          Хранение в SQLite
                    |
                    v
        Интерфейс приложения
```

Архитектура разделяет этапы обработки данных, NLP-анализа и формирования результатов, что упрощает развитие и расширение системы.

## 4. Используемые технологии

| Технология | Назначение |
|------------|------------|
| Python | Основной язык разработки |
| Pandas | Обработка и анализ данных |
| SentenceTransformers | Векторные представления текста |
| scikit-learn | Инструменты машинного обучения |
| SQLite | Хранение данных |
| Streamlit | Интерфейс для работы с результатами |

## 5. Применение методов NLP и ML

### Обработка естественного языка

NLP-компоненты используются для анализа текстовых отзывов, определения их тональности и тематической принадлежности.

### Векторные представления текста

SentenceTransformers предоставляет инструменты преобразования текстовых данных в числовые векторы (embeddings).

Векторные представления позволяют учитывать семантические особенности текстов и применять методы машинного обучения для их анализа.

### Классификация

Методы машинного обучения используются в задачах анализа тональности и тематической классификации отзывов.

Основные компоненты:
