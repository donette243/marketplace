# Marketplace AI — Анализ и автоматизация работы с отзывами

Этот проект представляет собой интеллектуальную систему для автоматизации работы с отзывами клиентов 
на маркетплейсах (Ozon, Wildberries, Яндекс Маркет и др.).

Система позволяет:

- централизовать отзывы клиентов
- автоматически анализировать их (тональность + тема)
- генерировать ответы с помощью ИИ
- улучшать качество клиентской поддержки

# Сбор и хранение данных

- Импорт отзывов клиентов
- Хранение в базе данных (SQLite)
- Структурирование данных для анализа

# NLP-анализ
# Определение тональности:

- положительный
- отрицательный
- нейтральный

# Классификация тем:

- доставка
- проблема с товаром
- качество товара
- другое

# Генерация ответов

- Автоматические ответы на отзывы
- Адаптация тона в зависимости от ситуации
- Обработка смешанных отзывов (позитив + жалоба)
